# Garet webfonts

Garet Book and Garet Heavy are the two free weights distributed by Type Forward for desktop and web use.

Foundry and usage statement: https://garet.typeforward.com/
Font package: https://www.dafont.com/garet.font
Downloaded September 19, 2026. The two free weights are included as WOFF2 for the website and converted TTF copies for social image rendering. Other Garet weights are not included or licensed by this project.
